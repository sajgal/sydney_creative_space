# www.sydneycreative.space

I always wanted to create my own gallery. I don't like to post on social media sites full of ads, AI slop and addictive algorithms. This one is built on serverless tech stack that is almost free to run. It has admin section that supports multiple users + superadmin, easy gallery management (CRUD), publishing scheduling, approval by supradmin.

## Tech stack
- tanstack start framework with Typescript
- images are hosted on Cloudinary (free tier)
- authentication is provided by Firebase (free tier)
- data persistency by Firestore (free tier)
- hosted on netlify.com (free tier)
- domain by porkbun (this is my only cost, but it's optional)
- code hosted on github

Check it online at [www.sydneycreative.space](https://www.sydneycreative.space)
